# 🛒 Sistema de Ventas

Versión básica de un sistema de ventas que funciona directamente en el navegador, sin instalar nada.

## ¿Qué hace?

- **Registrar productos** con nombre y precio
- **Hacer ventas**: toca los productos para armar el carrito y cobra con un clic
- **Resumen del día**: número de ventas y total vendido hoy
- **Historial**: lista de las ventas realizadas hoy, con hora y detalle

Los datos se guardan en el propio navegador (localStorage), así que no se pierden al cerrar la página.

## ¿Cómo lo uso?

1. Descarga el archivo `index.html`
2. Ábrelo con doble clic (se abre en tu navegador)
3. ¡Listo! Agrega productos y empieza a vender
